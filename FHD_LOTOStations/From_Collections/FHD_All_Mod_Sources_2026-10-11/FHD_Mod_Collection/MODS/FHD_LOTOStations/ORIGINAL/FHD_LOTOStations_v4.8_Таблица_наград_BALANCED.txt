ОБЩИЕ ПРАВИЛА НАГРАД
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
• Для выбора строки наград используется фактическое текущее звание игрока.
• Точное совпадение числа выдаёт денежный приз; начиная с Аса / Атамана дополнительно разыгрывается корпус.
• Корпус создаётся на текущем ГТУ и помещается на склад лотерейной станции.
• Качество корпуса в строках с джекпотом указано как: обычный / хороший / редкий.
• Оборудование выбирается случайно из допустимого пула и не превышает текущий ГТУ.
• Оборудование не из ЧД получает случайную расу-производителя из пяти рас Коалиции.
• Оборудование из ЧД остаётся оборудованием ЧД.
• Вес базового, обычного и среднего оборудования: случайно 10–100 т.
• Вес хорошего, очень хорошего, редкого и очень редкого оборудования: случайно 10–40 т.
• Для Атамана при ±1: 85% хорошее оборудование из ЧД / 15% редкое оборудование из ЧД.
• Микромодули выбираются случайно из допустимых для текущего звания и текущего ГТУ.
• Распределение качества микромодуля внутри допустимой категории: 60% / 25% / 10% / 5%.
• При пиратском ±2 сначала действует награда звания; шанс артефакта заменяет микромодуль, а не добавляется к нему.
• Шкипер: 2% артефакт любой расы; Головорез: 4%; Атаман: 5%.
• Хан: 7% артефакт из ЧД вместо редкого модуля.
• Барон: при ±2 всегда получает артефакт из ЧД.
• Артефакты не ограничены ГТУ.
• Новый розыгрыш начинается каждые 182 игровых дня и активен 60 игровых дней.
• На один розыгрыш разрешена одна попытка.
